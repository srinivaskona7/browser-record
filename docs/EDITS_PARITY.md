## 3. Explicit Remaining Gaps vs. Native Desktop Cap & Instagram Edits

1. **OS-Level Window Exclusion & True System-Wide Overlay (`Cap.app`)**:
   - Native `Cap.app` uses macOS `ScreenCaptureKit` / `CGWindowLevel` to float a native borderless window above full-screen spaces while excluding its own window ID from display capture.
   - In Browser Record, `src/capture/floatingCamera.ts` uses Chromium **Document Picture-in-Picture** (with **HTMLVideoElement Picture-in-Picture** fallback). When capturing an entire monitor (`displaySurface: 'monitor'`), the OS compositor includes any visible browser or PiP window on that monitor. The UI explicitly warns the user to choose **Window** or **Browser tab** capture when they want to exclude the recorder UI/PiP window.
2. **Cloud / Licensed Libraries & Proprietary AI Models (`Edits.app`)**:
   - Native `Edits.app` connects to Meta's licensed music catalog, Giphy/sticker CDN, AI background segmentation/cutout, and Instagram Direct publishing.
   - Browser Record is a 100% local, zero-account, zero-telemetry web application: users import their own audio/video/images or use the built-in procedural WebAudio SFX generator and local Whisper WebWorker transcription. No decorative buttons for unimplemented AI cutout, motion tracking, or social-network login are shown.
3. **Font Availability**:
   - The 406 font family catalog (`FONT_FAMILIES` in `src/effects/catalog.ts`) sets the CSS `fontFamily` stack on the Canvas 2D compositor; rendering of non-system display fonts requires either the font to be installed on the host OS or loaded by the browser.
